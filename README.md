# Kyiv Alert Widget

Мінімалістичний Android-віджет стану повітряної тривоги в місті Києві.

**Статус: віджет 2×1 перевірено на Pixel 10; новий дизайн, віджет 1×1 і діагностика запитів потребують перевірки на телефоні після встановлення версії 0.2.1.**

## Перша версія

- Особисте використання на Google Pixel 10; встановлення APK без Google Play.
- Два віджети головного екрана українською: великий 2×1 з текстом і компактний 1×1 з кольором, щитом і часом останньої успішної перевірки.
- Автоматичне оновлення; натискання на віджет запускає додаткову перевірку.
- Без видимих сповіщень, звуків і вібрації, без окремого щоденного інтерфейсу застосунку.
- Червоний / жовтий рівень / відбій; окремо — невідомий рівень та застарілі дані.
- Нульовий бюджет: лише безкоштовні тарифи, без платних підписок чи автоматичних доплат.

## Джерело даних

Офіційний API «Київ Цифровий»: `GET https://kyiv.digital/open-api/air-alert/state`, заголовок `Accept: application/json`.

[Документація](https://kyiv.digital/open-api/docs/air-alert.html) · [OpenAPI](https://kyiv.digital/open-api/docs/air-alert.yaml).

Webhook потребує токена від команди API. За поточною специфікацією він надходить на початок і відбій тривоги, але не на зміну типів загроз під час неї. Для повного стану потрібне також періодичне читання API.

Доставка фонових повідомлень на Android може затримуватися. Webhook не є гарантією миттєвого оновлення віджета. Час останньої перевірки та ознака застарілих даних — обов'язкові частини інтерфейсу. Віджет не замінює офіційне оповіщення.

## Поточний прототип

Код у `app/` містить віджети 2×1 і 1×1, іконку «Щит», прямий запит до API, оновлення натисканням та резервну періодичну перевірку через WorkManager з мінімальним інтервалом 15 хвилин. Обидва віджети оновлюються разом і реагують на натискання будь-де на плитці. Під час запиту вони зберігають останній підтверджений колір і час, показуючи невеликий індикатор оновлення. На першій перевірці стан сірий, а час — `—:—`. Великий віджет після успішного запиту показує секунди, компактний — години й хвилини.

Якщо перевірка не вдалася, віджети зберігають попередній стан і час останнього успішного запиту; помилка ніколи не перетворюється на відбій. Через 45 хвилин без успішної перевірки колір стає сірим. Для цього окремо планується локальна перевірка давності даних без мережевого запиту. WorkManager може затримати фонові задачі, тому віджет не слід сприймати як гарантовано миттєве оповіщення.

## Діагностика запитів

Кожна завершена перевірка API створює один запис з джерелом запиту, результатом, HTTP-кодом і тривалістю. Для помилки також записуються її категорія (`http_server`, `timeout`, `dns`, `connection`, `tls`, `invalid_response` тощо), етап запиту й назва класу винятку. Тіло відповіді, токени та повний текст винятку не зберігаються.

Записи видно в Android Logcat за тегом `KyivAlertWidget`. Зараз APK є налагоджувальним, тому з комп’ютера можна також прочитати приватний журнал останніх 100 запитів і окремо останніх 100 помилок:

```sh
adb logcat -d -s KyivAlertWidget:I
adb shell run-as ua.kyiv.alertwidget cat files/request-log.txt
adb shell run-as ua.kyiv.alertwidget cat files/request-errors.txt
```

Кожен із двох файлів обмежений 100 рядками й видаляється разом із застосунком. Старі рядки автоматично замінюються новими. Час у файлах подається в UTC; Logcat показує час відповідно до налаштувань перегляду. Ці записи не передаються на сервер.

Webhook-сервер і FCM ще не додані. Цей прототип потрібен для перевірки вигляду й базової поведінки на телефоні перед вибором безкоштовної серверної схеми. Автоматичне оновлення зараз забезпечує тільки WorkManager, тому зміна стану може відобразитися із затримкою.

Для локальної збірки потрібні JDK 17, Android SDK 36 та Gradle 8.13. Команда: `gradle testDebugUnitTest assembleDebug`. [GitHub Actions](https://github.com/Cheewbacca/kyiv-alert-widget/actions/workflows/android.yml) виконує її автоматично та зберігає debug APK як артефакт. [Перша збірка](https://github.com/Cheewbacca/kyiv-alert-widget/actions/runs/36404244028) успішно виконала тести й створила APK. Версію 0.2.1 слід перевірити на Pixel 10.

Debug APK у кожній збірці GitHub Actions може бути підписаний іншим тимчасовим ключем. Якщо Android не приймає його як оновлення вже встановленого прототипу, видаліть стару версію та встановіть нову: це також видалить локальні дані й віджет з екрана. Після встановлення додайте з вибору віджетів «Київ · Тривога» новий розмір 1×1. Перед постійним користуванням потрібно налаштувати окремий стабільний ключ підпису поза публічним репозиторієм.
