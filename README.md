# Kyiv Alert Widget

Мінімалістичний Android-віджет стану повітряної тривоги в місті Києві.

**Статус: планування. Застосунок і сервер ще не реалізовані.**

## Перша версія

- Особисте використання на Google Pixel 10; встановлення APK без Google Play.
- Віджет головного екрана українською: колір, текст статусу та час останньої успішної перевірки.
- Автоматичне оновлення; натискання на віджет запускає додаткову перевірку.
- Без видимих сповіщень, звуків і вібрації, без окремого щоденного інтерфейсу застосунку.
- Червоний / жовтий рівень / відбій; окремо — невідомий рівень та застарілі дані.
- Нульовий бюджет: лише безкоштовні тарифи, без платних підписок чи автоматичних доплат.

## Джерело даних

Офіційний API «Київ Цифровий»: `GET https://kyiv.digital/open-api/air-alert/state`, заголовок `Accept: application/json`.

[Документація](https://kyiv.digital/open-api/docs/air-alert.html) · [OpenAPI](https://kyiv.digital/open-api/docs/air-alert.yaml).

Webhook потребує токена від команди API. За поточною специфікацією він надходить на початок і відбій тривоги, але не на зміну типів загроз під час неї. Для повного стану потрібне також періодичне читання API.

Доставка фонових повідомлень на Android може затримуватися. Webhook не є гарантією миттєвого оновлення віджета. Час останньої перевірки та ознака застарілих даних — обов'язкові частини інтерфейсу. Віджет не замінює офіційне оповіщення.
